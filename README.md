# Supervisor / Executor Skills

用于制定执行任务、复审结果，以及实现和验证已定任务。每份 Skill 直接规定适用场景、输入、步骤、输出与停止条件，不包含角色定位或双方工作流设计的介绍。

> The skills are written in Chinese and can be used by coding agents that support SKILL.md.

## 文件

- [supervisor/SKILL.md](supervisor/SKILL.md) — 核依据和成果、确定取舍、生成任务、复审与交付。
- [executor/SKILL.md](executor/SKILL.md) — 读任务、核前提、自主实现、必要验证、收尾与回执。
- [AGENTS-template.md](AGENTS-template.md) — 可选的项目交接模板。

每份 Skill 可分别安装和使用，不依赖另一份 Skill。核心步骤及关键门禁必须向用户逐步明文输出：结果、状态、事实依据、下一动作；未输出或依赖门禁失败就不得继续，不能只写本地文件或事后补PASS。输出可在同一消息按序完成，不增加审批往返。

## 安装

```bash
# Codex CLI
cp -r supervisor executor ~/.codex/skills/

# ZCode
cp -r supervisor executor ~/.zcode/skills/

# Claude Code（项目级）
cp -r supervisor executor <你的项目>/.claude/skills/
```

## 使用

制定任务或复审结果时使用 /supervisor；实现或验证已定任务时使用 /executor。

沿用当前项目的交接文档，默认 AGENTS.md。新项目可复制 AGENTS-template.md 到根目录并重命名；已有项目只合并必要约束，不覆盖任务或强制重排格式。

交接保存当前有效的目标、状态、已定行为、约束、待决事项和执行任务。执行任务按可独立验收的用户结果拆分，逐项给对象/输入、编号步骤、预期与失败判据、证据来源和采集时点、时限/依赖与停止条件；不附完整选题论证，不预写普通实现细节。必要细节要一次写清，不靠写薄方案省token。

## 减少返工的约定

- **最小验收单元不等于最小派发包。** 完整用户结果的实现、输入/保存、页面操作、自动更新、结果与收尾一次写齐，同批连续完成；不能先执行、回来补页面、再回来补证据。
- **先校准必要方法，再批量做。** 普通页面操作和关键原件取得能力先验证；工具受阻不等于产品失败，不为测法问题先做昂贵外部动作。
- **按下发时的约定复审。** 做错、漏做、缺证、决策漏写、工具/资源受阻及新要求分别处理。新增标准单列增量，不能追溯判成执行失败。
- **逐项结算，继续主线。** 已通过且未受影响的结果保留，仅补失败/遗漏步骤，真实依赖以外的已授权工作继续；外围完善不占住主要目标。
- **没有新用户结果就明报业务推进0。** 辅助原件/映射PASS不等于功能完成；整轮成本包含执行、补正、复审、核证、交接和用户转发/等待，不能用退回代码0宣称往返少或降本。
- **前提未变，不重新派发。** 已失败的方法没有解除条件的新事实，不能再派“补步骤/恢复后再测”包；决定端承担前提判断，能续接时原完整链自动继续。

真实业务结果决定验收，不能用编译、HTTP 200或存活代替。有效原件复用，历史失败和未知保留；同目标累计投入和停止边界不因改名、换方法或换会话清零。没有依据不编工期或节省比例；必要安全收尾不省略。

会话、资源、提交、部署与外部发送权限遵用户和项目约定。有保留价值不等于有提交权限；代码交付不自动包括方案、日志、证据、交接或 Agent 配置。项目要求远程仅代码及必要配置时，其它材料只保留本地。Skill 发布到用户指定的技能仓库。
